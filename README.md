# 🧩 Sokoban Puzzle - Glitch Mechanic

"글리치" 테마의 소코반 퍼즐게임입니다. 플레이어만 통과할 수 있는 "글리치 벽"을 이용해 박스를 목표 지점까지 밀어 넣는 퍼즐을 풉니다.

## 🎮 핵심 규칙
- 플레이어는 글리치 벽(자홍색)을 통과할 수 있지만, 박스는 통과하지 못합니다
- 이 비대칭성을 이용해 일반 소코반과는 다른 경로/순서 퍼즐을 만듭니다

## 🛠 Tech Stack
- Unity
- C#

## ⚙️ Key Systems
- 텍스트 파일(ASCII 격자)을 읽어 레벨을 자동 생성하는 `LevelLoader` (데이터 기반 레벨 디자인)
- 좌표 비교 기반 이동/충돌 판정 (물리엔진 없이 순수 로직으로 처리)
